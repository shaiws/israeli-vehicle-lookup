- **Full description (EN):**
  Look up technical vehicle information for Israeli license plates using official Ministry of Transport datasets published on data.gov.il (CKAN datastore).

  Features:
  - Hebrew RTL interface
  - Active registry, fallback registries (motorcycle, heavy, public, inactive, cancelled), ownership/odometer history, and recall checks
  - Treats history hits as found when the active registry is empty

  Privacy: This app shows technical vehicle fields only. It does not provide owner identity or other personal information. Queries go directly to data.gov.il.

  Open-source companion web app: https://github.com/shaiws/israeli-vehicle-lookup
